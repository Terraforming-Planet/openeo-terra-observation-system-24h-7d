# Download the openEO integration

[Download ZIP](TerraObserver-openEO-integracja.zip?raw=true) or open the file and choose **Download raw file**. The package contains source code, two validation graphs, tests and setup documentation. It contains no private model assets, tokens or DEM rasters.

From the extracted directory: `python -B -m terraobserver.cdse --output /tmp/new-cdse-audit`. Python 3.10 or newer; no additional packages required.
